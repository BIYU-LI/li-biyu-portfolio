李碧玉个人作品集网站｜本地使用与部署说明

【网站文件】
- index.html：网站入口
- styles.css：视觉样式、响应式布局与动画
- projects.js：作品项目内容与图片数据
- app.js：交互逻辑（开场动画、筛选、弹窗、滚动动画、鼠标反馈）
- assets/：从 V5 作品集 PPT 中提取的作品图片与线稿素材

【本地预览】
1. 解压 ZIP 文件。
2. 进入解压后的文件夹。
3. 双击 index.html，即可用 Chrome / Edge / Safari 打开。
4. 建议使用桌面浏览器，窗口宽度 1280px 以上体验最佳；网站也适配手机和平板。

【交互说明】
- 首屏开场动画：点击 SKIP INTRO 可跳过。
- 作品筛选：按彩妆个护、保健护理、礼盒结构、电子烟 CMF 分类。
- 作品卡片：点击可打开项目详情与图片画廊。
- 系列作品：可拖动横向浏览，也可使用左右箭头。
- 鼠标：桌面端带有自定义跟随光标与 VIEW 提示。
- 页面滚动：标题渐入、进度条、盒型小角色移动等效果。
- 联系方式：邮箱和电话可直接点击联系。

【部署上线】
这是纯静态网站，不依赖后端或数据库。将整个文件夹上传到任意静态网站托管服务即可。
注意：上线时必须保留 index.html、styles.css、projects.js、app.js 与 assets 文件夹的相对路径结构。

【内容说明】
作品名称、设计说明、经历、项目数据和联系方式依据提供的《李碧玉个人作品集 V5》整理。
本网站不修改产品包装图片的设计内容；作品图片仅用于网页排版展示。
